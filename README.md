# red eye V1.0
A script that installs black hat hacking tools for Termux / Kali Linux
# install red eye

clone tool

git clone https://github.com/brdyamhrany-debug/red-eye.git

Entering the tools folder

cd red-eye

Giving access to tools

chmod +x "red eye.sh"

to run

bash "red eye.sh
